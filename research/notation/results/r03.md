<details><summary><code>overload+hash</code> (sha256 <code>7ace1e123237b2c4</code>)</summary>

````text
You are reading a sketch of a notation for a database language. Answer from the text below alone. Do not use any tools, do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are URIs like `bug:01`.
- `(name first label: value ...)` is a call: the first argument is positional, every other argument is labeled.
- `?x` is a variable. A call with variables is a question; it returns every match.
- A call whose name ends in `!` writes facts.
- `{a 1 b 2}` is a map.
- `(concept (name params...) body...)` defines a concept: the body says which facts make one up. Reading the concept matches those facts; writing it stores them.
- `(xyz.tonk.issue/title ?bug is: ?t as: :text)` is the fact (?bug, xyz.tonk.issue/title, ?t), whose value is text.

The definition:

```
(concept (bug ?bug title: ?t status: ?s)
  (xyz.tonk.issue/title ?bug is: ?t as: :text)
  (xyz.tonk.issue/status ?bug is: ?s as: :text))

(concept (bug title: ?t status: ?s)
  (bug (hash {xyz.tonk.issue/title ?t xyz.tonk.issue/status ?s}) title: ?t status: ?s))
```

Questions (answer each in 1-3 sentences, plus confidence low/medium/high):
1. `(bug! title: "typo" status: "todo")` gives no entity. Which entity are the facts stored on? Could you predict its id from the values?
2. That same write runs again tomorrow in another session. How many bugs titled "typo" exist afterwards?
3. Also `(bug! bug:01 title: "crash" status: "todo")` was run. Which bugs does the question `(bug ?b title: ?t status: ?s)` return? And which does `(bug title: ?t status: ?s)` return?
4. Later someone runs `(bug! title: "typo" status: "done")`. Does that update the existing "typo" bug or create a different one? Why?
5. Write a call that creates a bug titled "slow" with status "todo", letting the system choose the entity.
6. What does the name `bug` refer to, given it is defined twice? How does a call pick which definition applies?
7. Rate how clear the definition was, 1 (baffling) to 5 (obvious), name the one thing that confused you most, and say concretely what spelling would have made it obvious.

Reply with numbered answers only.
````
