<details><summary><code>V0 assert</code> (sha256 <code>bd1056c51d402d81</code>)</summary>

````text
You are reading a sketch of a notation for a database language. Answer from the text below alone. Do not use any tools, do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are URIs like `bug:01` or `person:ada`.
- `(name first label: value ...)` is a call: the first argument is positional, every other argument is labeled.
- `?x` is a variable. A call with variables at the top level is a question; it returns every match.
- `bug/status`, `bug/label` and `bug/assignee` are attributes of bugs. `(bug/status ?b is: ?s)` reads one; a call whose name ends in `!`, like `(bug/status! bug:01 is: "done")`, writes one.
Everything else you must infer from the text.

```
(assert (bug/stale ?b)
  (bug/status ?b is: "todo")
  (unless (bug/assignee ?b is: ?anyone)))

(assert! (bug/status! ?b is: "triage")
  (bug/label ?b is: "urgent")
  (bug/status ?b is: "todo"))

(retract! (bug/label! ?b is: "urgent")
  (bug/status ?b is: "done"))
```

Questions. Answer each in 1-3 sentences with confidence low/medium/high.
1. For each of the three forms: does what it produces get stored in the database, or is it only computed when asked? When does it take effect?
2. bug:01 has status "todo", and then label "urgent" is added. What does `(bug/status bug:01 is: ?s)` return afterwards? If label "urgent" is later removed, does the status change back?
3. bug:02 has status "todo" and no assignee, so it is stale. Then someone assigns it. Is it still stale? Why?
4. What does `!` mean in each place it appears here?
5. Write (a) a form that makes `(bug/open ?b)` true for bugs whose status is not "done", without storing anything; and (b) a form that stores assignee person:ada on any bug labeled "ui".
6. Rate how clear the three forms were, 1 (baffling) to 5 (obvious), name the most confusing thing, and say concretely what spelling would make it obvious.

Reply with numbered answers only.
````
