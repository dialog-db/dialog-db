The prediction is wrong on both counts. `steps` did not pass, and `example` did worse than the sentence it was meant to improve on.

## What `steps` changed

The six `steps` readers who scored got everything right, for dialog's reasons:

- Rule B reads the title rule A derives, so B fires.
- C finds nothing stored to retract.
- D stores "Fix login bug", which is newer than the issue fact, so `last` picks it.
- In question 9, the issue's change is newer than that store, so "Login fails" wins back.

The election rule did its job: none of them hedged on `last`. In `baseline`, by contrast, two of the three who scored (b) then kept "Fix login bug" in question 9, and one said it could not tell.

The four `steps` readers who missed gave the same reason as every miss in R27 and R28. One said outright that B's condition "matches stored facts only", with the sentence about derived values in front of it.

## Why the example failed

The example's domain call, `(xyz.book ?b title: ?t)`, returns the derived title, and readers used that in question 3. None carried it to rule B. Every one of the ten said B needs a stored `xyz.todo` title for `issue:7`, and that `issue:7` has only `xyz.tracker` facts.

All 20 misses in R27, the 13 in R28 and the 20 here follow one script:

1. Look up the prompt's list of stored facts.
2. Find no `xyz.todo` line for `issue:7`.
3. Conclude B cannot fire.

No documentation tried so far displaces that lookup reliably.

**What readers found hardest.** As in every round: telling a document's request (`rename`, `archive`) from a stored or derived fact, and when an effect lands.

## What follows

Every reader, in every round, already treats a concept call as reading stored and derived values alike: question 3 has never been missed. What readers will not grant is that a domain call does the same. R27's readers said why: the `xyz.` prefix is the only thing in the notation that marks a stored fact. So the misreading may be the notation's, not the documentation's. Rule B reads the stored layer by its spelling, and readers believe the spelling.

Two tests separate that from the prompt priming the answer:

- **B through the concept.** Rule B reads `(todo ?t title: ?old)` instead of `(xyz.todo ?t title: ?old)`, with no documentation. If readers then see the rename land, the guidance for rule writers is to read through concepts, and domain calls stay the layer agents expect.
- **No stored-facts list.** The same document, with the stored facts given as prose rather than a table of attributes. This tests whether the table is what readers check.
