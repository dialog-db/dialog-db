````text
You are reading a sketch of a notation for a database language. Answer from the text below alone. Do not use any tools, do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are URIs like `bug:01` or `person:ada`.
- `(name first label: value ...)` is a call: the first argument is positional, every other argument is labeled.
- `?x` is a variable. A call with variables at the top level is a question; it returns every match.
- A call whose name ends in `!` writes.
- `{a 1 b 2}` is a map. `;` starts a comment.
Everything else you must infer from the text.

```
;;; Attributes

(concept! (bug/title ?of is: ?is)
  (xyz.tonk.issue/title ?of is: ?is as: :text pick: :last))

(concept! (bug/status ?of is: ?is)
  (xyz.tonk.issue/status ?of is: ?is as: :text pick: :last))

(concept! (bug/label ?of is: ?is)
  (xyz.tonk.issue/label ?of is: ?is as: :text pick: :all))

(concept! (bug/assignee ?of is: ?is)
  (xyz.tonk.issue/assignee ?of is: ?is as: :entity pick: :last))

;;; A concept

(concept! (bug ?bug title: ?t status: ?s assignee: (option ?who))
  (bug/title ?bug is: ?t)
  (bug/status ?bug is: ?s)
  (bug/assignee ?bug is: ?who))

;;; Rules

(assert (bug/stale ?b)
  (bug/status ?b is: "todo")
  (unless (bug/assignee ?b is: ?anyone)))

(assert! (bug/status! ?b is: "triage")
  (bug/label ?b is: "urgent")
  (bug/status ?b is: "todo"))

(retract! (bug/label! ?b is: "urgent")
  (bug/status ?b is: "done"))

(assert! (bug! {xyz.tonk.issue/title ?t} title: ?t status: ?s)
  (bug let:new title: ?t status: ?s))
```

Questions. Answer each in 1-3 sentences with confidence low/medium/high.
1. In two separate documents, `(bug/label! bug:01 is: "urgent")` then `(bug/label! bug:01 is: "ui")`; also `(bug/title! bug:01 is: "a")` then `(bug/title! bug:01 is: "b")`. What do `(bug/label bug:01 is: ?l)` and `(bug/title bug:01 is: ?t)` return?
2. bug:02 has a title and a status but no assignee. Does `(bug ?b title: ?t status: ?s assignee: ?w)` return bug:02? If so, what is ?w?
3. What is the difference between `assert` and `assert!` here? When does each take effect, and is what it produces stored?
4. Which bugs does `(bug/stale ?b)` return?
5. bug:03 has label "urgent" and its status becomes "done". What happens, and when?
6. A document contains `(bug! let:new title: "typo" status: "todo")`. Afterwards, what exists in the database? Does the entity `let:new` still have facts?
7. Write (a) a rule: every bug labeled "ui" gets assignee person:ada, stored; and (b) a question: the titles of bugs assigned to person:ada.
8. For each of these, rate 1 (baffling) to 5 (obvious): attribute definitions, `pick:`, `(option ...)`, `assert` vs `assert!`, `retract!`, `unless`, `let:`. Then name the most confusing thing and say concretely what spelling would have made it obvious.

Reply with numbered answers only.
````
