You are reading a sketch of a notation for a database language. Answer from the text below alone. Do not use any tools, do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are URIs like `user:01`.
- `(name first label: value ...)` is a call: the first argument is positional, every other argument is labeled.
- `?x` is a variable. A call with variables is a question; it returns every match.
- A call whose name ends in `!` writes facts. Many devices write to the same database and sync with each other.
- `{a 1 b 2}` is a map, `[a b]` a vector, `:x` a keyword.
- `(concept (name params...) body...)` defines a concept: the body says which facts make one up. Reading the concept matches those facts; writing it stores them.
- `(rule (assert! fact) (when premises...))`: whenever the premises match, the fact is written.
- `(xyz.user/email ?u is: ?e as: :text)` is the fact (?u, xyz.user/email, ?e), whose value is text.

The definition:
```
(concept (user ?u email: ?e name: ?n)
  (xyz.user/email ?u is: ?e as: :text)
  (xyz.user/name ?u is: ?n as: :text))
```

Example writes:
```
(user! (hash email: name:) email: "a@x.org" name: "Ada")
(user! (hash email:) email: "b@x.org" name: "Bob")
(user! user:01 email: "c@x.org" name: "Cy")
```

4. Later `(user! (hash email: name:) email: "a@x.org" name: "Ada L.")` runs. Is that the same entity as Ada from the first write, or a different one? Why?
