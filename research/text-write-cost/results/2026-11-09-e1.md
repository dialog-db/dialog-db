Worktree `/home/claude/wt-e1` (branch `research/text-e1`), nothing committed.
All numbers below are measured unless marked **inferred** or **extrapolated**.

| trace | sha256 | txns | agents | raw floor |

Both end at ~21 KB of text. Every friendsforever transaction is one keystroke with no timestamps, so time policies run on clownschool only.

## What was built

- **Harness**: `rust/dialog-soak/examples/text_write_cost.rs`. It is one binary, and each variant and flush policy is a setting. It goes through the real repository path: `Branch::transaction().integrate().commit().publish()`, then `pull()`/`push()` against the soak's local-directory remote, with the soak's `simulation` transfer tally for wire bytes.
  - `raw`: compact varint encoding of `(agent, seq, parents as (agent,seq), [pos, del, ins])`. The common parent (the agent's own previous txn) is one byte.
  - `facts`: one fact per txn, `(doc, text/change, Bytes(change))`, `Pick::All`.
  - `doc`: one fact `(doc, text/content, String)`, `Pick::Last`. The text comes from applying patches in trace order with clamped positions. Its length is exact, its content approximate.
  - `region-canonical`: `PersistentTree<[u8;73], Vec<u8>>`, key `tag ‖ blake3(doc) ‖ blake3(origin) ‖ seq_be`, value = change body. `edit().persist()` per flush.
  - `region-buffered`: the same keys through `HitchhikerTree` with default buffers, `persist_mut` per flush.
  - `--sync`: one replica per agent, each with its own storage, repository and key, all tracking one server branch on the fs remote. Per window, each agent commits its own txns as one commit, then each replica in turn pulls and pushes. A final pull round follows.
  - Policies: `1|10|100|1000|all|second|pause:<s>`. `--limit N` replays a trace prefix.
- **Counting**: written bytes are distinct blocks by hash (nothing reclaimed) plus distinct blobs. Live size is what a fresh replica downloads with `pull().download()` (tree blocks plus blobs). For the regions, live size is the canonical one-shot tree of all changes. `TEXT_E1_BREAKDOWN=1` splits nodes by key tag.
- **One library change**: `rust/dialog-peer/src/helpers/metered.rs` gains `Meter::imported_blob` (a default no-op) and meters `blob::Import`. Without it, spilled values were invisible: the first doc runs showed 2.6 KB written for a 21 KB value. It is additive, so existing meters are unchanged.
- **Scripts**: `research/text-write-cost/harness/{run.sh,matrix.sh,summarize.py}`.
- **Results**: `research/text-write-cost/results/2026-11-09-e1/*.jsonl` + `tables.md`.
- `cargo fmt --all` and `cargo clippy -p dialog-peer -p dialog-soak --all-targets --all-features -D warnings` are clean. The workspace-wide clippy was not run.

Run:
```
RUSTUP_TOOLCHAIN=stable-x86_64-unknown-linux-gnu cargo build --release -p dialog-soak --example text_write_cost
research/text-write-cost/harness/matrix.sh /home/claude/data/editing-traces/concurrent_traces <results-dir>
python3 -I research/text-write-cost/harness/summarize.py <results-dir>/*.jsonl
```

**Repeatability (measured)**: three interleaved repeats of four configs gave byte-identical written, live and sync counts. ms/commit spread was about 5% (facts/100: 22.1 to 23.2 ms). The other timings are single runs on a 2-core VM with an in-memory store.

**Substitutions**:
- Facts at one commit per txn, facts per-second (clownschool), and doc per-txn (clownschool) ran out of the 7 GB of RAM on the full trace. They run on a 5000-txn prefix next to coarser policies on the same prefix.
- Region sync was not built as two replicas. Its "sync" is the per-flush novel blocks, which is what a single writer's push uploads. That is a proxy for upload only.
- H5 (accreting resource) was not built.

## Where the facts bytes go (measured, friendsforever, one commit)

The live tree holds 15.3 MB for 26 078 change facts, about 585 B per fact. Each fact lands in four regions at about 147 B per entry each: entity, attribute and value orderings, plus the history claim record. Index nodes are only 37 KB. Logical keys are about 40 B in the data regions and 80 B in history.

**Inferred**: the remaining ~100 B per entry is the per-entry payload (claim version, origin, cause) after columnar encoding. So the per-fact cost alone is ~56x the raw change, before any per-commit cost.

## Verdicts

The bar is "within 2x of a text CRDT library". Library numbers are not in yet, so the ratios below are to the raw floor. A library can only sit at or above the floor, so a variant at more than 2x the raw floor fails the bar if the library stores these traces near the raw floor. **Inferred**: libraries typically land at about 1 to 3x raw on these traces, but that needs the other agent's numbers.

- **H0 (a text change need not be a commit): refuted for changes-as-facts at every interval, including one commit for the whole trace.**
  - Measured: live size alone is 53 to 56x raw, and sync of a single commit is 59 to 60x.
  - Bytes do fall with the flush interval, but sublinearly at fine grain. From 10 to 100 to 1000 txns per commit, written bytes fall 1.9x then 4x on friendsforever. A bigger commit rewrites more: per-commit cost rises from 0.45 MB to 2.4 MB to 5.8 MB.
  - At an interval an editor would accept: per second is ~5800x (extrapolated), a 2 s pause is 1235x written and 3198x sync, and a 5 s pause is 238x written and 572x sync.
  - The per-commit floor the refute clause names is confirmed. At one commit per txn on the 5000-txn prefix, a commit writes 169 KB on average (median 66 KB).
  - H0's mechanism (accumulate, then flush) is still necessary, but it does not suffice with today's fact layout. The fact encoding costs 56x on its own.
- **H1 (text region in the tree): mixed. Storage passes against the floor, interactive sync fails.**
  - Measured: the region's live tree is 1.8x raw on both traces, with 73-byte keys and no claim or revision machinery.
  - Measured: each flush costs a fixed ~8 to 12 KB of rewritten leaf plus root. Per txn that is 746 to 1145x, per second 150 to 240x, and a 2 s pause 10 to 12x. Only at a 5 s pause or 1000 txns does it reach 3 to 4x raw.
  - So the refute clause ("node overhead dominates small changes") holds at per-edit and per-second intervals. Whether a pause interval is within 2x of the library stays open until library numbers arrive.
  - Region sync was measured only as upload proxy, not as a two-replica differential.
- **H5 (accreting resource outside the tree): not measured, left open.**
  - **Inferred** from the doc variant, which is one replaced fact per commit, like H5's heads pointer: a one-fact replacing commit costs a median of 45 to 80 KB and a mean of 170 to 230 KB per commit today. Those figures include a 10 to 20 KB spilled text blob, so a small pointer would cost somewhat less. Every flush would pay that on top of the change block.
  - So H5 beats H1 only if the pointer moves outside a Dialog commit, or the commit floor drops.

## Surprises and claims the numbers contradict

1. **The per-fact overhead (~56x raw, about 585 B/fact) dominates, not only the per-commit floor.** The design and topic notes frame the cost as per-commit, but batching everything into one commit still leaves Dialog more than 25x over any plausible library. The text cannot live as one fact per change in today's layout at any interval.
2. **Contradicted (text-write-cost.md prior): "one per second still in hundreds of megabytes"**. Per second on clownschool extrapolates to ~1.5 GB written, and on the prefix, three-replica sync moves 4x what a single replica writes. The "per edit is in gigabytes" prior is confirmed: about 11 GB extrapolated.
3. **Confirmed (single-file-format.md, text-write-cost.md): "~120 to 160 KB per commit of a couple of facts".** The measured mean is 169 KB per one-fact commit and the median 66 KB. The mean comes from buffer cascades and grows with history, from about 57 KB/commit in the first decile to about 244 KB in the last on the prefix.
4. **Doc-as-value live size grows with commits.** The history region keeps every replaced value: spilled blobs are referenced by claim records, so a fresh download fetches all of them. At one commit per txn, the 21 KB document has a 342 MB live size. This is consistent with version-control.md "Content erasure" (the log retains value bytes), but it means "replace the whole value" is not a cheap fallback either.
5. **The facts live size also grows with commit count**, from 56x at one commit to 221x at one commit per txn on the prefix. Each revision adds about 1.8 KB of records that never go away.
6. **Sync moves more than is written** for facts (about 1.4 to 1.6x of the bytes all replicas write). Both sides upload and download merge novelty, and every round pays a pull and a push.
7. **One commit of 26k facts takes 8 s** (5.8 s on clownschool), about 0.3 ms/fact. That is slow enough to matter for a bulk flush.
8. **Buffered vs canonical region**: the hitchhiker buffer cuts per-flush bytes by 35 to 45% at fine intervals. It changes nothing at 1000+ txns per flush.
9. **The Metered helper did not count blob imports**, and spilled values and large records go there. Any perf or soak number taken through `Metered` under-reports writes for large values. The harness change fixes this for E1 only; the `perf/baseline` and `soak/baseline` counters were not touched.
