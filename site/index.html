Dialog Local-first database

An embeddable database for local-first software. Facts you own, synced through any storage, queried with Datalog.

Read the guide Code

Facts

Everything is a small statement about a thing. No tables and no migrations: a new kind of data is a new attribute.

Local first

Every device keeps its own replica. Reads and writes never wait on a network, and replicas converge when they sync.

Yours

Everyone is a key. Access is a signed capability, not an account on someone's server.

Everywhere

One Rust core, native and in the browser, with a query language in the family of Datalog.
