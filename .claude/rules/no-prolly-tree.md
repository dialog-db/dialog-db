# Never say "prolly tree"

The tree structure DialogDB stores facts in is a **probabilistic search tree**
("probabilistic B-tree" is also fine). Our implementation is the **dialog
search tree**, in the `dialog-search-tree` crate.

Never call it a "prolly tree", in code, comments, docs, notes, commit
messages, pull requests or conversation. If you find that name in this
repository, replace it: "probabilistic search tree" when the text means the
general structure, "dialog search tree" when it means our implementation.
Cite prior art by the title of the work, not by giving our tree its name.
