# A replica that holds every block still pays to warm it: claims

| claim | kind | backing | status |
|---|---|---|---|
| `warm_source`'s only guard before walking is `routes.fetches(subject)` | fact | `rust/dialog-repository/src/repository/fetch.rs`, `warm_source` | holds |
| `fetches` is true when any open branch of the subject tracks a remote route, whatever that branch's head holds | fact | `rust/dialog-repository/src/repository/archive/routes.rs`, `Registered::fetches` | holds |
| warming is advisory: a walk's error is dropped, and with a zero budget queries return the same rows with no speculation | fact | `fetch.rs`: "Warming is advisory"; test `it_refuses_hints_and_flows_demand_with_a_zero_budget` | holds |
| on `query-member` the phase runs 503 walks over 1,020 nodes, fetching nothing; the phase is about 120 M instructions and a walk about 19 K | fact | `perf/baseline/query-member.json` (`span.warm_walk`, `span.warm_node`); `notes/fetch-scheduler.md`, "A warm walk on a local member" | holds on main at e755416 |
| `query-member` is the only perf baseline that records a warm walk | fact | `grep '"span.warm_walk"' perf/baseline/*.json`: every other scenario records 0 | holds |
| the perf gate allows no growth in any `span.*` counter, so a new counter that rises from absent fails it | fact | `rust/dialog-perf/src/compare.rs`, `Tolerance::step_slack` is 0 | holds |
| `query-member`'s member adopts the main branch's tree by a pull from a local upstream; it never commits | fact | `rust/dialog-perf/src/scenario/member.rs`, `view` | holds |
| `forget` releases a repository's per-repository caches and scoped nodes; routes and writers stay | fact | `rust/dialog-perf/src/env.rs`, `forget`; `rust/dialog-repository/src/repository/caches.rs`, `release` | holds |
| the archive offers get, put, import and load, and no delete: a block once local stays local through the API | fact | `rust/dialog-effects/src/archive.rs` | holds; storage wiped outside the API is not covered |
| a pull makes its new head by fast-forward (the upstream tree by hash), by graft (subtrees of the upstream tree by hash) or by replay | fact | `rust/dialog-repository/src/repository/branch/pull.rs`, `prepare_upstream` | holds |
| `Download::Everything` drains an export with download reach; each item is local by the time it is yielded | fact | `rust/dialog-repository/src/repository/branch/download.rs`, `DownloadBranch::perform` | holds |
| the catchup and join soak clients adopt their head by `MinimalRanges` from a remote; the join scenario's `Everything` client reads nothing after its download | fact | `rust/dialog-soak/src/catchup.rs`, `rust/dialog-soak/src/join.rs` | holds |
| the join scenario's seeded device commits on an empty tree, which D would record, and then only pulls, replaying onto the remote tree; it reads nothing in between | fact | `rust/dialog-soak/src/join.rs`, the `seeded` phase | holds; bears on H3 |
| a memo of walked (root, range) pairs buys little, since hints are point probes that rarely repeat | hypothesis | #767's pull request body; would be refuted by counting distinct (root, range) pairs among one phase's 503 hints and finding most repeat | open, not re-tested here |
| running speculation only while demand is pending starves a partial replica's prefetch and breaks the catchup soak's drain contract | fact | #770's pull request body; `rust/dialog-soak/src/catchup.rs` | holds |
| H1. a tree made by applying instructions to a wholly local tree (or the empty tree), with the nodes it minted persisted, is wholly local | hypothesis | confirmed by a test that commits on a recorded tree and then traverses the new tree through an environment that does not hydrate, finding no absent block; refuted by any node of the new tree that is neither minted nor reachable from the base | open |
| H2. with the record, `query-member`'s `span.warm_walk` and `span.warm_node` go to 0, and the phase falls by about 9.5 M instructions | hypothesis | confirmed by `perf` on `query-member` against `perf/baseline/query-member.json`; refuted if any walk runs | open |
| H3. the replication gate shows no change, since no soak client's head is recorded by the two writers | hypothesis | confirmed by `soak:sweep --networks none` and the shaped catchup and join scenarios against `soak/baseline/`; refuted if any metric moves | open |
| H4. the tonk member branches that showed about 18.5K walks per query hold every block of their head | hypothesis | confirmed if, on such a branch, the walks of one query fetch nothing and the branch's head was made by commits on its own or by a full download; refuted if the branch pulls with `QueriedRanges` or `MinimalRanges` and its walks fetch | open; decides whether D helps tonk at all, and whether E or P2 comes next |
| H5. one environment's held state never serves two archives of one repository | hypothesis | confirmed by tracing every holder of `HeldCaches` to one storage; refuted by any environment that holds caches for two stores of one subject. If refuted, a record made against one archive skips walks against another: a cost, not a wrong result | open |
| the record should not be dropped by releasing or clearing caches: it says something about the archive, and nothing re-derives it | opinion | the agent, 2026-11-12 | for the maintainer |
| surviving a restart is not taken on until H4 is known | opinion | the agent, 2026-11-12 | for the maintainer |
| a pull's replay arm is not made a writer in the first step: a missed record costs a walk, a wrong one costs a partial replica its prefetch | opinion | the agent, 2026-11-12 | for the maintainer |
