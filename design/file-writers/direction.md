# Direction

**Decision:** how a space's writers store blocks so that processes on
separate branches never wait on one another, while the space is still kept
in one file.

**For:** many processes work on separate branches of one space at once; on
main they never wait on one another to write, and the single-file archive
makes every write take one file's writer turn
([the problem](../file-writers.md#problem)).

| criterion \ approach | Status quo: every writer appends to the one file, in turns | Loose blocks and an integrator: writers put blocks as files of their own (main's `fs` archive); an integrator folds them into the file later; reads look in both | A journal per writer and an integrator: each writer appends to a file of its own; the integrator folds those files in | One owning process: every writer reaches the space through one process that writes the file (Dolt's server) | Append when the turn is free, else loose blocks: a writer tries the file's turn without waiting; with it, it appends directly as today and folds in any loose blocks waiting; without it, it puts loose blocks and schedules integration |
