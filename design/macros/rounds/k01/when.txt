You are using a notation for a database language. Work from the text below alone. Do not use any tools other than the one Read you were told to make, and do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are written like `todo:1` or `list:home`.
- `(xyz.todo ?t text: ?x state: ?s)` is a read. It matches every entity that has those fields. `?t`, `?x`, `?s` are variables; a constant such as `:open` in a field's place matches only that value.
- A command is something a person issues, for example `(complete (xyz.todo todo:1))`. It holds only at the moment it is issued. Nothing is stored by issuing it.
- A rule is `(rule head… (when premise…) (unless premise…))`: one or more heads, then the premises inside `(when …)`, then, if there are any, the premises that must not hold inside `(unless …)`.
- A head says what the rule gives. `(assert! A)` stores A, and it stays stored. `(retract! A)` removes A. A head with neither word derives A: it holds for as long as the premises hold, and is never stored.
- A premise says what has to be there: a read, or a command someone issued.
- `(unless …)` holds when what is inside it has no match.
- A rule with several heads writes them one after another, before `(when …)`.
- A write may also stand on its own, outside a rule, with a `(when …)` after what it writes. It is short for the rule with that head.

Two rules, as examples:
```
(rule (assert! (xyz.todo ?t state: :done))
  (when (complete (xyz.todo ?t))))

(rule (xyz.pending ?t text: ?x)
  (when (xyz.todo ?t text: ?x state: :open)))
```
