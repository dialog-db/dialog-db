You are using a notation for a database language. Work from the text below alone. Do not use any tools other than the one Read you were told to make, and do not search files or the web.

Basics you can rely on:
- The database stores facts: entity, attribute, value. Entities are written like `todo:1` or `page:a`.
- `(xyz.todo ?t text: ?x state: ?s)` is a read. It matches every entity that has those fields. `?t`, `?x`, `?s` are variables; a constant such as `:open` in a field's place matches only that value.
- A command is something a person issues, for example `(complete (xyz.todo todo:1))`. It holds only at the moment it is issued. Nothing is stored by issuing it.
- `(assert! A)` stores A, and it stays stored. `(retract! A)` removes A. Something a rule gives with neither word is derived: it holds for as long as what the rule needs holds, and is never stored.
- `(unless …)` holds when what is inside it has no match.

Nobody has told you how a rule is written. These three rules are all you have:
```
(rule (assert! (xyz.todo ?t state: :done))
  (when (complete (xyz.todo ?t))))

(rule (xyz.pending ?t text: ?x)
  (when (xyz.todo ?t text: ?x state: :open)))

(rule (xyz.blocked ?t by: ?b)
  (when (xyz.todo ?t after: ?b state: :open)
        (xyz.todo ?b state: :open))
  (unless (xyz.waived ?t)))
```

Task A. Read these two rules:
```

  (when (xyz.link ?a to: ?b)

```
The database stores four facts and nothing else: `(xyz.link page:a to: page:b)`, `(xyz.link page:b to: page:c)`, `(xyz.link page:c to: page:d)`, `(xyz.link page:x to: page:y)`.
